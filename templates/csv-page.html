Import Releases

Upload a CSV file to import or update releases. The header row must include UPC/EAN.

Supported Columns: UPC/EAN, Release Title, Artist, Release Date, Release Format, Record Label, Distributor, Buy Now Link, Bandcamp Shortcode, Tags, Featured Image URL, Audio Preview URL, About, plus {Provider Name} Link columns (e.g. Spotify Link, Apple Music Link, or any custom provider configured in Settings).

Upsert Behavior: Existing releases matching UPC/EAN on the current site are updated in place instead of creating duplicates.
